# Métricas de Investimento

## Análise de risco

- Correlação (Δ Risco, Liquidez, Retorno)
- **P/VP** → Ancoragem, oportunidade de risco

## Fundos

- Avaliar: vacância, CRI e alavancagem
- **Alavancagem** = Passivo Total / Ativo Total
- Alavancagem até **30%**

## Ações

- **P/L**: escala de 0 a 15
  - 0 a 3: atenção
  - 3 a 10: confortável
  - 10 a 15: atenção
- **ML** (margem líquida)
- **Dívida Líquida / EBITDA**: Energia < 5; outros < 3; (observação sobre bancos — trecho de difícil leitura)

## Preço Teto

### Benjamin Graham — Valor Intrínseco

```
Valor Intrínseco = √(22,5 · VPA · LPA)
VPA = Patrimônio Líquido / número de ações
```

### Bazin — Preço Teto

```
Preço Teto Bazin = Média dos dividendos pagos nos últimos 3 anos / 0,06
```

## Índice de Sharpe

```
Sharpe = (Retorno do Ativo − Taxa Livre de Risco) / Volatilidade (Desvio Padrão)
```

## Correlações e análises

- Correlação entre: taxa Selic, fundo de papel e fundo de tijolo
- Análise de RI: RI antes da queda e próximo
- Analisar: taxa de administração, fundo de performance, liquidez, DRE, rendimento por cota, saldo acumulado
- Análise gráfica

## Preço Teto para FII

```
Preço Teto FII = Provento esperado por cota / Dividend Yield desejado
```

> Provento é anual x12.

## Versão Ajustada de Warren Buffett

```
Preço Justo = Lucro por ação · (8,5 + 2g)

Preço Justo = (LPA · (8,5 + 2g) · 4,4) / Taxa de Juros Atual
```

- **g** = taxa de crescimento anual estimado dos lucros nos próximos anos
